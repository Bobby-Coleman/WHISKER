WHISKER

A knight. A kitten. A road they can only cross together.

Models, scenery, textures, atmosphere, sound effects, and music in the default game are generated by this project's code. The reference video is a visual guide and is not included in the distribution.

  • Character skeleton and animations: Quaternius Universal Animation Library, Library 2 — CC0 1.0. The runtime files retain the required skeleton and tracks; unseen mannequin meshes and unused animations are omitted.
  • three.js — MIT. License and copyright notice.
  • Rapier / Dimforge — Apache 2.0. License. The physics library is used without modification.

The source repository also contains optional legacy experiments using CC0 Poly Haven skies and surfaces and CC0 Quaternius props. These are omitted from the lean default-game release. Source and asset credits remain with those experiments.
